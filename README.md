# Shamo

A calm, personal daily dashboard for tracking energy, routine, chores and food — built to support a sustainable 50% work restart after burnout.

Five views:

- **Today** — a low-pressure daily plan (walk, work/gym, up to 2 "elephants", meals, one household task, recovery block, bedtime routine). Nothing is marked "failed" — items just move to tomorrow.
- **Elephants** — max 2 important 50-minute focus blocks per day, each followed by a mandatory 10–20 minute break.
- **Food & Home** — weekly meal plan, grocery list, laundry/cleaner reminders, and a "Do I really need this today?" prompt (yes today / can wait / add to next order).
- **Week** — the 5-day/2-week work rhythm (work → recovery → work → recovery → work/off), colour-coded by day type (work / recovery / kids-holiday / leave / weekend).
- **Insights** — energy, overwhelm and sleep trends over time, plus a weekly balance wheel across work, movement, recovery, children, home and self.

All data is stored locally in your browser (no account, no server) — it's private to your device.
